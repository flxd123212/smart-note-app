# 📋 智能便签 - Smart Note & Workflow Scheduler

一个简洁、强大的桌面应用，帮你智能捕获信息、管理任务、安排工作流程。

## ✨ 功能

- **🧠 智能捕获** - 输入文字时自动识别日期、时间、优先级和标签
- **📝 任务管理** - 创建、编辑、删除、拖拽排序任务
- **🔗 工作流程** - 将任务组织成流程，可视化工作顺序
- **📅 日历视图** - 按日期查看任务分布
- **🔔 提醒通知** - 到达提醒时间时弹出系统通知
- **⚙️ 智能安排** - 新建任务时询问是否自动安排到空闲时段
- **🌙 深色模式** - 跟随系统主题或手动切换
- **🔄 开机自启** - 开机后自动启动应用
- **💾 系统托盘** - 最小化到托盘，后台运行；托盘图标支持左键切换窗口、右键菜单操作
- **🪟 单实例运行** - 重复点击 exe 不会创建多个进程，自动聚焦已有窗口
- **🆕 自动更新** - 启动后自动检查 GitHub Releases 新版本，一键下载安装

## 🚀 快速开始

### 前提条件
- Node.js >= 18
- npm >= 8

### 安装

```bash
cd smart-note-app
npm install
```

### 运行开发模式

```bash
npm start
```

### 打包为 EXE

```bash
# 打包为安装程序 (NSIS)
npm run build

# 打包为便携版 (单文件 exe)
npm run build:portable
```

打包后的文件在 `dist/` 目录下。

### 直接启动

也可以直接双击 `启动.bat` 来启动应用。

## 📖 使用指南

### 快速添加任务
1. 点击「新建任务」按钮
2. 输入任务内容，例如：`明天下午3点开会 #工作 高优先级`
3. 系统会自动解析日期、时间、标签和优先级
4. 点击保存

### 智能安排
当创建一个没有指定时间的任务时，应用会询问是否自动安排到空闲时段。

### 创建工作流程
1. 切换到「工作流程」视图
2. 点击「新建流程」
3. 选择流程中的任务并命名
4. 任务按顺序排列显示

### 深色模式
在「设置」中可以选择「跟随系统」、「始终深色」或「始终浅色」。

### 关闭与托盘行为
在「设置 → 启动与托盘」中：

- **开机自启动**：开机后自动运行应用
- **最小化到系统托盘**：
  - **开启**：点击窗口关闭按钮时，窗口隐藏到系统托盘，应用继续后台运行；点击托盘图标可重新显示，右键托盘图标选择「退出」彻底退出
  - **关闭**：点击窗口关闭按钮时，应用直接退出，无后台残留

### 版本与自动更新
在「设置 → 关于与更新」中：

- 显示当前版本号（开发模式下会标注「开发模式」）
- 点击「🔍 检查更新」手动检查 GitHub Releases 是否有新版本
- 发现新版本后按提示下载，下载完成后重启即完成安装
- 应用启动 10 秒后会自动静默检查一次（不打扰，仅在设置页提示）

## 📁 数据存储

应用数据存储在用户数据目录：
- Windows: `%APPDATA%/smart-note-app/`

包括 `tasks.json`（任务数据）和 `settings.json`（设置数据）。

## 🚀 发布与自动更新

自动更新依赖 GitHub Releases：

1. 将 `package.json` 中 `build.publish[0].owner` 改为你的 GitHub 用户名
2. 首次发布：`npm run build` 后用 [GitHub CLI](https://cli.github.com/) 或网页上传 `dist/` 下的 `latest.yml` + 安装包到 Releases：
   ```bash
   gh release create v1.1.0 "dist/智能便签-1.1.0-setup.exe" "dist/latest.yml" --title "v1.1.0"
   ```
3. 之后每次 `npm run build` 都会读取当前版本号，配合新 Release 即自动推送给已安装用户

> 注意：打包的版本号取自 `package.json`，发布新版本前先改版本号。
