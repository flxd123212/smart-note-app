# 📋 智能便签 - Smart Note & Workflow Scheduler

一个简洁、强大的桌面应用，帮你智能捕获信息、管理任务、安排工作流程。

## ✨ 功能

- **🧠 智能捕获** - 输入文字时自动识别日期、时间、优先级和标签
- **📝 任务管理** - 创建、编辑、删除、拖拽排序任务
- **🔗 工作流程** - 将任务组织成流程，可视化工作顺序
- **📅 日历视图** - 按日期查看任务分布
- **🔔 提醒通知** - 到达提醒时间时弹出系统通知
- **⚙️ 智能安排** - 新建任务时询问是否自动安排到空闲时段
- **🌙 深色模式** - 跟随系统主题或手动切换
- **🔄 开机自启** - 开机后自动启动应用
- **💾 系统托盘** - 最小化到托盘，后台运行；托盘图标支持左键切换窗口、右键菜单操作
- **🪟 单实例运行** - 重复点击 exe 不会创建多个进程，自动聚焦已有窗口

## 🐛 最近更新 (v1.0.1)

- **修复：关闭窗口后无法从托盘唤回** - 窗口被真正关闭后，点击托盘图标 / 右键菜单「显示主窗口」会自动重建并显示窗口，不再无响应
- **修复：关闭窗口后程序永不退出** - 关闭「最小化到系统托盘」开关后，关闭主界面即彻底退出进程，不再有后台残留
- **优化：单实例锁** - 应用只允许一个实例运行，重复启动时自动唤醒已有窗口
- **优化：托盘图标** - 使用应用图标（`assets/icon.ico`）代替默认绿圆点，加载失败时自动降级

## 🚀 快速开始

### 前提条件
- Node.js >= 18
- npm >= 8

### 安装

```bash
cd smart-note-app
npm install
```

### 运行开发模式

```bash
npm start
```

### 打包为 EXE

```bash
# 打包为安装程序 (NSIS)
npm run build

# 打包为便携版 (单文件 exe)
npm run build:portable
```

打包后的文件在 `dist/` 目录下。

### 直接启动

也可以直接双击 `启动.bat` 来启动应用。

## 📖 使用指南

### 快速添加任务
1. 点击「新建任务」按钮
2. 输入任务内容，例如：`明天下午3点开会 #工作 高优先级`
3. 系统会自动解析日期、时间、标签和优先级
4. 点击保存

### 智能安排
当创建一个没有指定时间的任务时，应用会询问是否自动安排到空闲时段。

### 创建工作流程
1. 切换到「工作流程」视图
2. 点击「新建流程」
3. 选择流程中的任务并命名
4. 任务按顺序排列显示

### 深色模式
在「设置」中可以选择「跟随系统」、「始终深色」或「始终浅色」。

### 关闭与托盘行为
在「设置 → 启动与托盘」中：

- **开机自启动**：开机后自动运行应用
- **最小化到系统托盘**：
  - **开启**：点击窗口关闭按钮时，窗口隐藏到系统托盘，应用继续后台运行；点击托盘图标可重新显示，右键托盘图标选择「退出」彻底退出
  - **关闭**：点击窗口关闭按钮时，应用直接退出，无后台残留

## 📁 数据存储

应用数据存储在用户数据目录：
- Windows: `%APPDATA%/smart-note-app/`

包括 `tasks.json`（任务数据）和 `settings.json`（设置数据）。
